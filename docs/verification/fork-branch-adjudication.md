# Fork `fm/*` branch adjudication and durable retention review

Audience: maintainer verification.

This is a time-bound, committed evidence snapshot for the fork branch-retention decision.
It records verdicts only and authorizes no deletion, rename, force-push, or other ref mutation.

## Scope and controls

The inventory contains the 153 accumulated remote-tracking refs matching `refs/remotes/fork/fm/*` at the time of this check.
It excludes `fm/fork-branch-adjudication`, the delivery branch created after the inventory snapshot to carry this document.
The target is `fork/main` at `45c179bb783680ae451b86eaa8f94f6f3625729e`, the merge commit that joined the fork carries with the upstream line.
Every verdict uses `git merge-base fork/main <ref>` and measures the branch delta from that merge base.
This record deliberately does not use a tip-to-tip diff against `fork/main`.

## Limitation: durable abandonment evidence

Forge evidence can establish activity, never abandonment.
Absence of a pull request is not absence of an owner.
Every former `superseded` or `genuinely abandoned` row was checked against the authoritative protected-branch inventory, relevant primary-home `state/*.status` records, `state/decision-bindings/`, and the main-deck pure-Kun reroute and reset orders.
A `genuinely abandoned` verdict requires a positive durable abandonment record; it is never inferred from a missing PR, a non-ancestor ref, or a search with no match.
Tip ancestry establishes only direct commit reachability, not shipment.
A squash merge replaces a branch tip with a new commit on `fork/main`, so a non-ancestor tip cannot disprove that its PR landed.
PR merge state is authoritative for the landed verdict, and rows whose tip differs from the landed commit note that delivery shape.
Each inventory ref was also queried against the fork's all-state PR records by head branch; 29 returned no matching PR, and the two otherwise-unattributed matches (#86 and #87) are recorded below as closed unmerged.
The protected inventory records `fm/fm-backend-activity-provenance` as fork-absent by design; because it is absent from the fork inventory, it has no table row and its absence receives no verdict.

Positive control: `refs/remotes/fork/fm/reconciler-abort-attribution` resolved to `8e357a1c272710f906a07698166ce83d6261aacd`, and `git merge-base --is-ancestor fork/fm/reconciler-abort-attribution fork/main` exited zero.
That known merged PR #149 branch proves the exact `fork` remote-ref and reachability probe used for every row.

## Verdict meanings

- **landed**: the branch tip is reachable from the stated `fork/main` commit, or its associated PR is merged; a squash or rebase delivery may leave the tip non-ancestral.
- **preserved on purpose**: the branch has a current open PR or durable retention evidence, including a protected-branch or main-deck preservation record.
- **superseded**: the branch is not reachable from current `fork/main`, and durable evidence establishes a merged or recut replacement without a stronger preservation hold.
- **unknown**: the branch is not reachable and the durable-record check did not establish a retention, replacement, or abandonment disposition.
- **genuinely abandoned**: an explicit durable record says the branch itself is abandoned; it is not inferred from forge metadata.

A superseded verdict records ref disposition after fork-carry reconciliation, not a claim that every historical patch identity remains byte-identical in the current tree.
